🛠️ Tool Reference

Selection (🔲): Activates rectangular marquee. Drag on grid to select area. Enables batch tools (Fill, Cut, Delete).

Fill (🎨): Batch-paints the current selection or a row/column with the active tile.

Undo/Redo: History stack for all tile placements and grid modifications.

Export/Import: Serializes level state to JSON for persistence and sharing.

📊 Data Output Definitions

Foreground (Grid): A linear array of hex codes representing tile indices. These are copied directly into the world data tables in your ASM.

Pipes (🚪): Logic links for warp behavior. Defines Source (X, Y) coordinates and Target destinations (Level index and Entrance side).

Firebars (🔥): Entity definitions for rotating hazards. Tracks X/Y pivot, Length (tiles), and Speed/Direction of rotation.

Platforms (🪜): Moving surface data. Defines the Path (Start/End), Speed, and Type (Horizontal/Vertical) for the game engine.

⌨️ Advanced Interaction

Right-Click (Object Properties): Right-click on special tiles like Pipes, Firebars, or Platforms to configure their properties. This opens a modal to set warp destinations, rotation speeds, or movement paths.

Right-Click (Grid Utility): Right-click on standard tiles to access the Context Menu for row/column operations (Fill/Clear) and selection management (Cut/Copy/Paste).

Ctrl + Wheel: Adjusts viewport scale (25% for overview, 200% for precision tiling).

Shortcuts

  • S — Toggle select mode
  • Ctrl+X / C / V — Cut / Copy / Paste selected tiles
  • Ctrl+S / O — Quick Export / Import
